Microservices Reliability Demo Platform

A runnable local system showing microservices, Docker Compose, Docker Swarm, Kubernetes, Terraform, Ansible, Prometheus, Grafana, SLI/SLO, incident simulation, and recovery.

Architecture

Browser frontend calls the API Gateway. The gateway forwards requests to six services. Prometheus scrapes metrics and Grafana displays dashboards.
